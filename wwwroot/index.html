1. Authenticate

On dotnet run (Development), session tokens are auto generated into the local .NET User Secrets key store and print the file path (not the values). Open that secrets.json, copy a plaintext hex token, paste it here, then sign in. When you stop the app (Ctrl+C), The tokens clear.

2. Open the file browser

Can share UI state without server-side HTML rendering

Features to highlight

  • Require a valid Bearer token (authn) and role policy (authz) on every file API.
  • Canonicalize paths server-side and keep them under SandboxHome.
  • See README.md, threat model, and docs/DEPENDENCIES.md.
